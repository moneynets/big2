# 三人大老二（私人連線版）

## Windows 安裝
1. 安裝 Node.js LTS（https://nodejs.org/）。
2. 解壓縮本專案，進入資料夾，在資料夾路徑列輸入 `cmd`。
3. 執行 `npm install`，接著執行 `npm start`。
4. 電腦瀏覽器開啟 http://localhost:3000。
5. 同一個 Wi-Fi 下的朋友可用 `http://你的電腦區域IP:3000` 加入；跨網際網路遊玩須將專案部署至支援 Node.js / WebSocket 的雲端主機，並設定 HTTPS。

## 遊戲方式
房主建立房間，複製邀請網址給兩位朋友。三人進房後房主點「開始遊戲」。點選手牌，再按「出牌」，或按 Pass。

## 自訂規則
- 52 張普通牌＋大王小王；三人各 18 張，全部發完。
- 梅花 3 持有者先出，第一手必須包含梅花 3。
- 大小王只能單張，大王 > 小王 > 黑桃 2。
- 牌型：單張、對子、三條、順子、同花、葫蘆、鐵支、同花順。
- 五張牌型比較：同花順 > 鐵支 > 葫蘆 > 同花 > 順子。順子為連續 5 張，A 高、2 不參與順子。
- 兩位其他玩家 Pass 後，最後出牌者重新領出。
- 第一位出完手牌者獲勝。

## 目前版本注意事項
- 伺服器記憶體暫存房間；重新啟動會清空所有房間。
- 重新整理同一分頁可使用 sessionStorage 內的房間憑證重新加入；若換裝置需重新入房（牌局開始後不允許新身分加入）。
- 沒有玩家帳號、積分、聊天、計時或自動代打。
- 僅供熟人私人遊玩，房號不是強認證；請勿將邀請網址公開。
